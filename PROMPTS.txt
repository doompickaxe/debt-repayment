1.
Create a monorepo that combines a Quarkus backend which serves an Angular frontend. The Quarkus backend should use the latest Java 25 with Gradle. It should also be the latest Angular with yarn.
Additionally, I would like to have a openapi specification which generates the API for the backend as well as a client for the frontend.

2.
This project is a calculator to showcase how a debt develops with repayments each month. The user enters 4 pieces of information: The amount of the payout, the yearly interest, period of the loan as well as the percentage of redemption.

Change the openapi specification so that only one POST `/api/debt-repayment` endpoint exists.
In the request body contains the 4 parameters, while the response body is a list of objects that allows the creation of the table with the columns: Month, Remaining Debt, Amount of paid interest in that month, amount of repayment for that month, instalment.
